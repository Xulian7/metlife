# Dominio

La herramienta esta pensada para consultores que visitan clientes y necesitan entender rapidamente la relacion comercial, diagnosticar necesidades y guardar evidencia de recomendaciones.

El sistema distingue entre dato capturado, calculo, alerta, oportunidad comercial, recomendacion y concepto juridico. Ninguna recomendacion comercial debe presentarse automaticamente como obligacion juridica.
